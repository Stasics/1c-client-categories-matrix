# Матрица категорий клиентов (1С:Предприятие 8.3)

> Интерактивная форма для управления категориями клиентов в виде двумерной матрицы

---

## 📋 Pet-проект


Разработана управляемая форма в виде **двумерной матрицы**, где:
- **Строки** — клиенты
- **Столбцы** — категории
- **На пересечении** — флажки принадлежности клиента к категории

---

## 🎯 Реализованный функционал

| Функция | Описание |
|---------|----------|
| **Справочники** | Категории, Клиенты (код + наименование) |
| **Регистр сведений** | КатегорииКлиентов (независимый, непериодический) |
| **Матричная форма** | Двумерная таблица с флажками |
| **"Все категории"** | Массовое проставление флажков для клиента |
| **"Все клиенты"** | Отображение сводной информации по категориям |
| **Стандартные команды** | Записать, Записать и закрыть, Перечитать |
| **Отчёт на СКД** | Вывод клиентов по выбранной категории |
| **Проверка уникальности** | Запрет дублирующихся кодов |
| **Сортировка** | По алфавиту (клиенты и категории) |
| **Историчность** | Периодический регистр с выбором даты |
| **Массовое назначение** | Выбор нескольких клиентов → назначение категории |
| **Экспорт/Импорт Excel** | Выгрузка и загрузка матрицы |

## 🚀 Как использовать

1. Загрузи конфигурацию в 1С:Предприятие 8.3
2. Открой форму «Категории клиентов»
3. Отметь флажками принадлежность клиентов к категориям
4. Нажми «Записать» — данные сохранятся в регистр

---

## 📚 Что можно проверить

- [ ] Открыть матричную форму — увидеть таблицу с клиентами и категориями
- [ ] Поставить флажок в колонке «Все категории» — отметить все категории для клиента
- [ ] Снять флажок с категории — автоматически снимается «Все категории»
- [ ] Нажать «Записать» — данные сохраняются в регистр
- [ ] Открыть отчёт — выбрать категорию, увидеть список клиентов
- [ ] Добавить нового клиента — он появляется в матрице
- [ ] Добавить новую категорию — появляется новый столбец
- [ ] Экспортировать матрицу в Excel

## 🛠️ Использованные механизмы

| Механизм | Что реализовано |
|----------|-----------------|
| **Справочники** | Категории, Клиенты |
| **Регистры сведений** | КатегорииКлиентов (непериодический + периодический) |
| **Управляемые формы** | Форма набора записей, матричная таблица |
| **СКД** | Отчёт по выбранной категории |
| **События** | ПриСозданииНаКлиенте, ПередЗаписью |
| **Обработчики** | ПриИзменении для флажков |
| **Excel** | Экспорт/Импорт через табличный документ |
